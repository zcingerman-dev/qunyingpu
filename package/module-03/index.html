本项目玩法规则

主公可随时指定一名其他存活角色为储君，仅一次，不分担伤害。主公死亡时，存活的忠臣储君继位：体力上限+1、回复1点体力，继承原主公所有牌和主公技。主公存活时，储君死亡或转为野心家，取消储君资格，主公扣1点体力上限并流失1点体力；同一储君只惩罚一次。第二轮开始后，存活主忠人数少于存活人数一半时，内奸可随时成为忠臣或独立野心家；每次操作实时判定。野心家获得手杀版飞扬、跋扈，以及一次性的1枚野心家标记。仅在自己的回合内（包括额外回合及濒死时），可消耗标记摸两张牌或回复1点体力；回合外濒死也不可使用。未使用则跨回合保留，消耗后不补充；满血不可选择回复。击杀奖惩沿用标准身份场，获胜须独自存活。
