## 已完成内容

1. 技能框仅通过角色下三分之一或“技能”按钮打开。上、中部单击不打开；选目标期间，角色点击优先用于选目标，“技能”按钮仍可查看说明。本地双击换肤和关闭弹窗后的暂停状态恢复保留。
2. 乐曹植“赋”的文字仅在当前玩家自己的手牌中显示；卡牌交给其他玩家、进入处理区或弃牌堆后隐藏。实体规则标签和赋乐原技能逻辑保留。联机公开卡牌、其他玩家选择数据和公开按钮不附带私人赋标签。
3. 本地联机与互联网房间共用 `network-table.js`，显示包体原有立绘、牌桌背景、图像手牌、图像选将、体力、手牌数量、装备／判定数量、当前回合与操作选择。本人手牌通过原 ACTION 提交，目标可点击角色或目标按钮，技能说明按“技能1、技能2……”排列。
4. 显示层只读取 PlayerView。未公开的身份、国战暗将、他人手牌和私人选择继续过滤；未明置角色使用占位图。Host 权威、protocolVersion、原座位 Snapshot 重连和防重复 ACTION 保留。
5. 开局后收起大标题，并压缩房间信息区，给牌桌留出空间。README 已同步交互说明和显示模块路径。

## 最小人工检查

1. 在本地新局单击角色上、中部，应不打开技能框；单击下三分之一或“技能”应打开。选目标时点击角色应选中目标。
2. 使用乐曹植，确认本人手牌可见“赋”；交给其他玩家或进入公共区域后，原视角不显示该文字。
3. 两个客户端进入互联网房间并开局，确认立绘选将和图像手牌；各完成一次出牌／响应。查看技能后继续操作，Client 刷新仍恢复原座位。双方从“联机事件与状态核对”查看公开状态摘要，应一致。
