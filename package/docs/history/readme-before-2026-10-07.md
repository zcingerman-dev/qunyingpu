## 启动与使用

双击本目录的「启动群英谱.cmd」，打开 http://127.0.0.1:8767/index.html。
运行期间保留启动窗口。若端口已被旧版实战入口占用，关闭旧启动窗口后重新启动。

首页提供人物 Wiki、基础实战、我的、AI辅助及本说明。人物 Wiki 保留人物索引、关系图谱、版本技能图、资料编辑、保存历史和资料控制台；基础实战保留身份场、国战、斗地主、单挑，以及逐席选将、牌堆编辑、本地扩展、手动接管、对局控制台和记录回放。

人物详情的「实战体验此版本」会打开对应的实战版本资料；点击「将此版本带入选将」，再选择玩法、准备阵容。仅当该版本在当前合法将池内时才会预选，未接通的扩展资料不会当作白板参战。实战版本详情也可跳回对应人物资料。实战页打开 Wiki、首页或说明时使用新标签页，让当前牌桌保持运行。

## 当前评价口径与阶段

当前为基础玩法及技能文本粗评，不是完成训练的强度结论。
「极强」满足以下任一可重复条件：每轮稳定过至少 20 牌、每轮稳定令敌方掉至少 4 血，或大概率每轮进行至少 10 次攻击行为。过牌计入摸牌与其他实际获得牌，含额外回合及回合外获得，开局手牌不计；同次获得只记一次。摸牌总数和摸牌价值单独展示，锦囊权重 1.7、装备 1.3、其他 1。
评价按地主、农民、单挑、身份场分别保存，玩家可修改；国战不做双将强度评级。技能文本粗评可能遗漏复杂条件，需要实际对局验证。

八次重抽、默认 100 局 API 优化、固定独立策略及针对对手的测试位于 AI辅助。普通基础实战仍是体验，不自动形成强度排名。
复杂扩展仍按加载状态标示；双将技能正常叠加，循环保护触发时按和局结束，但未对全部扩展组合完成逐一实测。

## 我的与图片

“我的”仅在本机保存。收藏项包含具体武将版本和皮肤；基础实战选将的“收藏夹”可同时选多个，按版本合并去重。同一武将若有多个皮肤，取所选收藏夹中的首个匹配皮肤。皮肤仅改变立绘，不改变技能。

DIY 设计保存为独立版本：填写名称、体力、势力、立绘和技能文字；手写代码或进入 AI辅助生成草案，检查后点击“确认发布此版本”。已发布设计进入“本地扩展”将池；草稿不进入实战。修改设计另存新版本；已经被对局引用的版本保留。所有自定义技能 ID 应使用传入的 `prefix`，扩展需返回一个武将的 character、skill、translate 对象。

上传图片会显示原图预览、缩放和矩形内容选取；“使用整图”或“使用选取区域”后，同时保留原图和结果。图片支持 PNG/JPEG/WebP/GIF，原图及裁剪结果各上限15 MB，单批上传上限60 MB；图片独立存储，增加素材不会反复提交整个图片库。删除仍被 DIY 或收藏皮肤引用的素材时，界面列出引用并要求先替换；从素材库移除后，本机仍保留图片底稿以保证旧对局能够回放。背景选图同样支持预览和裁剪。

## AI辅助与 API 配置

顶部配置仅有服务商、API 地址、账户可用模型、API 密钥、每次最大输出 token 五项。输出上限默认 4096。取消价格、货币、调用次数和费用预算输入；底部“确定”附近显示累计已知输入/输出 token，用量缺失时单独标为未知。列表接口可用时点击“读取可用模型”提供选择，服务商不支持时可手填。模型是否有权限以真实调用结果为准。

密钥按 API 地址区分，默认仅留在当前本机服务内存。只有手动打开“密钥保存选项”并勾选保存时，才使用 Windows 当前用户 DPAPI 加密保存；导出不含密钥。外部 API 仍按服务商规则收费，本模块不根据缺失的 token 用量虚构账单。

选择 Codex / OpenAI API：在 [OpenAI 密钥平台](https://platform.openai.com/api-keys)创建密钥，使用 `https://api.openai.com/v1`，读取或填写账户可用模型，设置输出上限并确定。接口使用 [Responses API](https://developers.openai.com/api/docs/guides/responses)。DeepSeek 和其他兼容服务使用 Chat Completions；豆包 API 使用火山方舟，模型可能需要账户推理接入点 ID。图片草案生成需要支持图片输入的模型。

### 桌面工作模式

服务商菜单包含 Codex 工作模式、豆包工作模式及其他桌面工作模式。这些模式使用本机任务通道，沿用客户端登录和当前模型，无需填写 API 密钥。点击“生成本机任务指令”，复制到能操作本机文件和命令的工作客户端，启动后点击“检查工作通道”。任务涵盖技能草案、合法行动、优化与报告，仍由本地引擎结算。只运行在云端且无法访问本机的客户端不能直接连接。

工作工具位于 module-04/desktop_worker.py，连接文件临时生成在 data/desktop-runtime。指令给出对应 inbox、answer 文件：客户端读取 prompt/合法候选，把回答 JSON 和 lease 写入 answer 文件，工具提交结果。连接凭证只用于本机任务队列，不是 API 密钥，不进入个人导出；服务重启后需重新生成。主动断开、90 秒心跳中断或任务 5 分钟未回答时暂停，旧 lease 的回答会被拒绝。客户端退出但工具仍运行时，等待超时后暂停。

Codex 本机直接接入另提供官方 [app-server](https://developers.openai.com/codex/app-server) 适配，读取本机登录及模型列表、创建临时回答任务，不复用当前聊天。工作状态 SQLite 缓存独立放在 data/codex-runtime。模型回答使用结构化结果，禁用命令、插件和网页工具；原登录目录不复制密钥。当前开发环境的后台启动仍返回本机访问拒绝，尚未完成此适配的真实模型验证；启动失败会提示切换已完成离线通道验收的工作模式。豆包及其他工作客户端也需用户在客户端实际启动任务，不能把普通聊天窗口冒充入站 API。

桌面模式的每次 token 上限为指导值，当前适配无法硬性保证；只能展示客户端提供的准确用量，未提供则标“未知”。工作模式通道已通过离线替身的原生引擎优化、断线续跑、固定策略实战和报告验收；未把替身结果视为模型能力或真实武将强度。

### 收藏详情与检索

收藏中点击头像或姓名可查看该具体版本的完整技能、来源、势力、体力和美术素材；更换皮肤不会修改技能。AI 指定测试将、对手、副将及手动席位后展示立绘，可点击查看技能和素材预览。

武将检索支持中文、无声调全拼、首字母、常见多读音和同音错字。例如 `yuejin` / `lejin` 都可检索乐进，`居授` 可检索沮授；显示名保留原文，同音匹配在选将列表标注。同音模糊匹配用于至少两个汉字的姓名检索，单字仍按文字或拼音匹配。选将弹窗中精确匹配优先，多词同时生效；不把读音不同的任意错字强行归为同人。拼音词表取自原资源包的 pinyin-pro 3.27.0，转换为本地检索词表，无需连接外网。

DIY 生成只把图片与技能文字交给模型，生成原生技能代码及待确认规则。代码是草案，由你审核后另存新版本和发布。模型不会为了胜率改技能数值；发现文字与实现不一致时只提出修复草案。

实战测试提供身份场、国战、斗地主、单挑。单挑双方须指定；其他模式必须指定测试将，其他席可手动选取，或从收藏夹/武将包随机。国战需要合法双将配队。空筛选表示全当前合法将池，筛选条件同时生效。

## 实战报告与口径

报告区分优化与固定策略实战，按模式与身份显示胜率、首轮过牌、平均每轮过牌及牌价值、最高单次/每轮伤害、平均每轮伤害、敌方失牌、队友摸牌、各牌获得数量及 key 牌使用/获得频次与胜负关联。伤害只计原生伤害造成的敌方实际掉血，不把直接失去体力算作伤害。

每轮过牌包含摸牌与其他实际获得，含额外回合和回合外，排除开局发牌及重抽；同次获得去重，虚拟牌/实体牌各记一张。牌价值为锦囊1.7、装备1.3、其他1。敌方失牌只计实际离开手牌/装备区，排除判定区：因响应测试将行为失牌记“响应失牌”；因测试将技能记“技能失牌”，兼有两者时技能优先；普通卡牌造成的失牌另外列出。队友摸牌只计测试将行动或技能促成，普通摸牌阶段不算援助。平均每轮指标以测试将参与的轮数为分母，结束时未完的一轮计入并保留标记。

和局计入胜率分母；故障及人为写入/接管的干预局单列，排除胜率。新流程按有效局完成数量，另列故障尝试；旧报告保留旧局数口径。胜率低于20%时明确提示“本次测试中该武将强度过低”，并保留对手条件；这不是跨所有对手的严格强弱排序。key 牌关联不等于因果或数学最优解。

“我的 → 实战报告”可查看逐局日志/回放、修改备注与分析、导出或删除整项测试。原始日志与数值不可手动改写。控制台支持查看、暂停、写入、手动接管；干预行为随日志保留。
