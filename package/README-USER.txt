群英谱 Windows x64 便携版

一、启动
完整解压ZIP到可写目录（中文和空格均可），双击“启动游戏.cmd”。
无需安装Python、Node、pip、npm、Git或IDE。启动成功后默认浏览器自动打开。
建议Windows 10/11及Edge/Chrome。运行时保留启动窗口，关闭窗口或按Ctrl+C停止本次启动的服务。
不要直接在ZIP内部启动，不要放在只读目录。

二、本地游戏
进入“基础实战”，选择身份、国战、斗地主或单挑，选将后开局。
保留了当前正式/test武将包、DIY武将、技能改良与素材，包括觉醒势赵云和测试服神姜维。
已有DIY的发布/未发布状态原样保留。未发布版本须自行在“我的”确认发布后才能用于实战。
发行副本不带原来的对局、军八测试场次、优化测试局或API凭据。

三、联机
每台玩家电脑先启动各自的游戏本体。
同一电脑测试两个客户端：另双击“启动本机联机信令.cmd”，双方填ws://127.0.0.1:8771/signal。
局域网自建：房主双击“启动局域网信令.cmd”，双方填ws://房主局域网IP:8771/signal。
进入“临时互联网房间”，Host创建房间并分享邀请码，Client输入同一信令地址和房间码加入。
双方手动Ready、选将后由Host开始。对局内可开启/取消本人托管，整局暂停仅Host可操作。
Host退出关闭房间；Client短暂断线可按现有规则恢复原座位。
仅有邀请码不能替代共同可达的信令服务。不同外网需要可共同访问的信令地址及STUN/TURN；包内不提供付费服务器或TURN账号。
信令只处理房间和连接协商，游戏规则仍由Host执行。

四、常见问题
网页拒绝连接：检查启动窗口是否还在、ZIP是否完整解压；查看.runtime/logs中的最新日志。
端口占用：已有本项目服务会复用；其他程序占用会提示，不会自动结束其他程序。
找不到运行时：重新完整解压，不要只复制启动脚本。不要从未知网站单独下载DLL。
Windows防火墙：本地单机不需要开放公网；局域网信令需要时只允许信任的专用网络。
联机连接失败：双方检查信令地址、网络和STUN/TURN配置；127.0.0.1始终指各自电脑。
AI页面：需要使用者自行配置模型API或安装/登录相应桌面AI客户端，凭据不随包提供。
