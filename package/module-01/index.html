需求与交付边界

电脑端验收；各模块独立交付，验收后再组合。

01

Wiki 与武将关系

覆盖包体武将和不同版本；区分史实、作品与包体设定。纯虚构人物归入“其他”，真实人物的架空版本保留版本标签。包内简介和搭配关系保留出处，史实关系另行核实。

02

纯 AI 单挑

支持任意决策点手动接管和交回 AI，以及观战、暂停、逐步运行、倍速、回放。接管或修改状态的对局保留记录，单独标记。

03

武将通用策略训练

API 大模型操作武将，与无技能白板对战。白板最高 40 血，训练默认 100 局且可修改；训练结束固定独立操作策略，保留版本与训练记录。

04

针对对手的策略

双方先针对对手进行操作优化，再进行正式实战。针对策略和通用策略分别保存；正式测评固定策略，使用独立对局，不在测评中继续优化。

05

开局重抽与测评

正常发牌后最多额外重抽 8 次；每次整手替换、无费用、不保留单张。AI 决定留下或继续，不能预知下一手。统计零重抽和最多重抽 8 次的首轮过牌、先手秒杀概率等，附条件和样本量。

06

界面、扩展与存储

电脑端参考手杀布局，支持背景切换。各对局模式支持扩展内容与控制台，规则和状态修改留痕。数据本地保存、可导出与回滚；真实 API 接入时配置模型、密钥与费用上限。

工程默认值及尚未接入的配置见需求文件。本页面是模块 01 的资源验收入口，游戏对战与训练将在各自模块中交付。
