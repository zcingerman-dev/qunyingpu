1. 子动作 unpack、alpha 统一解析。unpackPremultipliedAlpha 只在 actionParams.name 与待机 player.name 相同（同骨骼）且没写配置时才继承待机，否则默认 false，避免待机 unpack 套到独立骨骼（攻击、特殊、换闪等）。
2. alpha：配置写了就以配置为准；没写时若本次要 unpack 则默认开预乘混合，否则跟 player.alpha。预加载、普通出框、连续出框、出框流程里都走这套。
3. 独立骨骼出框：出框前按上面规则算本次 unpack 和 alpha；需要 unpack 且资源还没按 unpack 加载会先卸了重载，和预览一致。playSpine 前临时设 Animation 的 unpack 和参数里的 alpha，播完恢复成待机用的 unpack，不误伤待机。
4. 指示线、爆炸等：指示线没写 unpack 时，只有特效骨骼名和待机角色名一样才回退到待机的 unpack；子特效 alpha 没写就按 unpack 和 player.alpha 推，写了以配置为准。
5. 换闪：shan 类参数在 huanshashan 上 Object.assign 合并 action、json、version、showTime，其余字段（alpha、unpackPremultipliedAlpha、scale、speed 等）从皮肤配置原样带过去，不只剩白名单几项。
6. 替换插槽：replaceSlots 为 [[槽位名, 图或资源], …]，播放时换槽贴图，Region/Mesh 常见情况能处理。replaceSlotUrls 为 [[槽位名, 图片 URL], …]，运行时 fetch 后替换，并记着每帧/更新后重贴，防被动画状态冲掉。预览里还能按槽调透明度、隐藏槽位，状态可记到当前预览节点下次恢复。
7. 复制名称：预览文件树里骨骼文件右键或触屏长按复制骨骼名（无扩展名），有提示。槽位列表里槽位名可双击、右键或长按复制。
8. Spine 节点：曾想在 playSpine / 构造里统一把配置 alpha 和 premultipliedAlpha 对齐，已撤回/*/有点麻烦不想写/*/。现在还是 premultipliedAlpha = 入
参的 alpha。alpha 只写在 playSpine 第二个参数里、不在首参里，可能和构造不一致，自己注意写法。
9. playEffect / playEffect2方法播放：可带 followSprite（或写在首参 sprite.followSprite）一次播两个骨骼；主轴 track0 每次 complete（含 loop 一轮结束）时处理从轴。effectPairOnMasterComplete：resetFollow 默认把从轴 trackTime 置 0 与主轴周期对齐；stopFollow 则清空从轴轨道并结束。effectPairSyncMaster：primary 表示听第一个 sprite 的 complete，follow 表示听 followSprite 的 complete。双骨骼都要能播时照旧 preloadEffects 或分别 preload。

配置备忘

unpackPremultipliedAlpha：纹理上传是否 unpack。配置里的 alpha：预乘混合，建议和 unpack 一起考虑，不然容易边发黑、颜色不对。待机开了 unpack 不会自动给不同骨骼名的子动作，子动作要自己写 unpack / alpha（同骨骼可按上面继承）。

```js
daiji: {
  unpackPremultipliedAlpha: true,
  alpha: true,
},

huanshashan: {
  name: 'xxx_shan',
  unpackPremultipliedAlpha: true,
  alpha: true,
},

replaceSlots: [
  ['slot_name', 'path/to/image.png'],
],
replaceSlotUrls: [
  ['slot_name', 'https://example.com/tex.png'],
],
```
