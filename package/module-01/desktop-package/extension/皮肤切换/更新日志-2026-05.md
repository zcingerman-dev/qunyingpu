# 更新说明

- 出框结束改为听 Spine 动画 `complete` 再回待机；支持待机特殊 `daijiteshu` / `play2Action`、换闪叠层；换闪与待机不同骨骼时走叠层；出框前会停待机叠层。
- 换闪（`huanshashan`）：仅在你写了配置时才带 `version`、`json`，其余由引擎自动识别 skel/json/版本。
- 播放头像动作：传入带 `name` 的对象时会按 `play2` 规则发 `play2Action`。
- 特效画布：新增第三层 **`playEffect3`**（**z-index: -2**）、**`stopEffect3`**；可选 **`preloadEffect3` / `preloadEffects3`**。

**示例：**

```js
skinSwitch.chukuangWorkerApi.playEffect3(sprite, position)
skinSwitch.chukuangWorkerApi.stopEffect3(sprite)
```
