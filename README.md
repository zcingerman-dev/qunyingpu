# 群英谱

三国杀人物 Wiki、本地实战、个人 DIY 与多人联机的 Windows 整合项目。

**下载完整便携版：[夸克网盘](https://pan.quark.cn/s/ecbb3918af01?pwd=p9Hz) · 提取码 `p9Hz`**

版本：`v1.0.0`。网盘链接由发布者提供，截图显示永久有效。发布者已人工核对，网盘文件为此前验收的便携版 ZIP；目前未单独提供 SHA-256 校验值。

## 普通玩家如何使用

1. 下载便携 ZIP，完整解压到可写目录。
2. 双击 `启动游戏.cmd`，等待默认浏览器打开，运行时保留启动窗口。
3. 使用人物 Wiki、我的收藏／DIY，或进入基础实战。

支持 Windows 10/11 x64，使用 Edge／Chrome 等浏览器。便携包自带 Python 和 Node，无需安装开发工具。当前已修改数据、test 将包、觉醒势赵云、测试服神姜维和已有技能改良保留；原测试对局、模型调用、账号凭据与浏览器缓存不随包提供。

## 当前功能

| 模块 | 内容 |
| --- | --- |
| 人物 Wiki | 武将版本、技能资料、检索筛选、关系图谱、来源记录 |
| 本地实战 | 身份、国战、斗地主、点将单挑；选将、托管、牌堆配置与回放 |
| 临时互联网房间 | 四模式、真人＋AI、Host 添加已发布 DIY、隐藏信息隔离、Client 刷新重连 |
| 我的与 DIY | 收藏、独立武将版本、逐技能编辑、自选皮肤、素材管理 |
| AI 辅助 | 技能草案、武将改良、后台策略优化与外接桌面工作通道；需要用户自行接入模型 |

身份立储／内奸择途属于本地专项规则；当前互联网身份场为标准身份。国战按现有双将规则运行。不会因为发布重新开启旧扩展加载器。

## 联机

每位玩家运行自己的本体。使用相同的可达信令地址，Host 创建房间，Client 用房间码加入；所有真人 Ready 后，由 Host 开始，再手动选将。对局内可开启本人托管。

同机测试使用 `启动本机联机信令.cmd`；局域网使用 `启动局域网信令.cmd`。`127.0.0.1` 只指当前电脑。跨公网需要共同可达的信令及可用 STUN；无法直连时还需自有 TURN 配置。这个仓库和网盘不提供公共信令、TURN 账号或云端游戏服务器。Host 退出关闭房间；Client 默认两分钟内可以使用原会话恢复原席位。

详见 [联机使用说明](docs/NETWORK.md)。

## 阅读和运行源码

GitHub 保存代码、资料索引和干净初始数据；大体积美术、字体、音频及便携运行时在上面的网盘包内。**GitHub 的 Download ZIP 是源码，不是完整便携版。**

完整源码在 `package/`，其内部相对路径与发行包一致。普通玩家直接使用便携版；开发者先解压便携包，在本仓库运行 `准备源码.cmd`，输入便携包根目录；工具只补齐清单中的外置资源及缺失初始数据库，不覆盖源码或已有个人数据。随后双击 `启动源码.cmd`。补齐资源与运行环境后，源码版同样可以使用完整功能。详见 [源码准备与构建](docs/SOURCE.md)。

AI 修改前阅读 [维护说明](package/readme.md) 和 [贡献边界](CONTRIBUTING.md)。已有 PASS 保持冻结，角色及技能 ID 保留；不要全仓逐技能重审或调整技能平衡。
