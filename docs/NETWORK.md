# 临时互联网房间使用说明

每位玩家先启动自己电脑上的完整本体。仓库页面及网盘链接不是游戏服务器。

## 信令与连接

| 使用场景 | 设置 |
| --- | --- |
| 同机双浏览器 | 启动本机信令，双方使用 `ws://127.0.0.1:8771/signal` |
| 两台局域网电脑 | 信令所在电脑启动局域网信令，双方使用 `ws://信令电脑局域网IP:8771/signal` |
| 异地互联网 | 使用双方共同可达的实际公网信令地址，优先 `wss://你的域名/signal` |

默认 STUN 用于尝试直连，不能替代信令服务。必要时双方配置实际可用的 TURN 地址、用户名与凭据；有有效 TURN 才能勾选强制中继。包内不提供公共服务器或账号。页面显示“本机服务在线”只说明本体可访问，信令是否连接看创建／加入反馈。

## 开局

1. Host 选择身份、国战、斗地主或单挑，设置总人数与真人人数，其他席位由 AI 补齐。
2. Host 创建房间并分享六位房间码；Client 填写相同信令地址和房间码加入。
3. Host 如需已发布 DIY，先在房间将池选择并应用，变更会重置 Ready。
4. 所有真人已连接且 Ready 后，只有 Host 可以开始。
5. 真人手动选将，随后进入对局。托管只在对局内开启，每位真人只能控制自己的托管。

Host 退出关闭房间，不迁移房主。Client 刷新／短暂断线默认两分钟内用原浏览器会话恢复原 playerId 与 Snapshot；新浏览器或清除会话不保证恢复原席位。断线不自动托管。Client 只接收授权 PlayerView，不能直接执行正式引擎。

互联网身份场当前为标准身份，立储／择途属于本地规则入口。没有账号、排位、好友、匹配大厅或观战服务。
